Struktur Silabus Mata Kuliah Pemrograman Web

Mata kuliah ini membekali mahasiswa dengan kompetensi rekayasa aplikasi web modern. Berikut adalah pembagian materi ajar:

  1. Klien (Front-End)
    • Modul 1: Fondasi Arsitektur Web & HTML5 Semantik
    • Modul 2: Standardisasi Kode & Pengorganisasian Konten
    • Modul 3: Rekayasa Media Digital & Dasar CSS
    • Modul 4: Tata Letak Grid, Flexbox, & Bootstrap
  1. Sisi Server (Back-End)
    • Modul 5: Pemrograman PHP Modern
    • Modul 6: Pemodelan Basis Data Relasional
    • Modul 7: Manipulasi SQL & phpMyAdmin
